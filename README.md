# Levi Glass Portfolio

Frontend portfolio satu halaman dengan:
- Glassmorphism UI
- Responsive dashboard layout
- Animated background/orbs
- Cursor glow
- Scroll reveal
- Counter animation
- 3D tilt card
- Sticky topbar
- Mobile navigation
- Live clock
- Active section navigation

## Jalankan
Cukup buka `index.html` di browser.

Untuk mengganti email, edit:
`mailto:hello@example.com`

Untuk mengganti nama, project, skill, dan teks portfolio, edit `index.html`.
